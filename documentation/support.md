# Support

This handoff contains the template source and development guides. No live support service or real venue email is configured. Use the installation/customization guides first; sample contact addresses in the UI are placeholders.

For a reproducible issue report, record the affected page, browser/version, viewport width, theme, direction, steps, expected result and observed result. Check documentation/testing-report.md for the verified scope. Reset local demo data in Settings when testing initial-state behavior. Preserve the supplied third-party licenses when redistributing assets.
