# Dashboard guide

Client screens share the same browser-local bookings used by admin. New Booking embeds the public workflow. My Bookings supports search, status/date filters, detail dialogs and pending-demo cancellation. Catering and Decoration screens save quantity-based enhancement estimates separately from existing reservations. Payment Installments records simulated payments, shows balances, dates and payment history. Invoices select a booking and support browser printing/PDF saving. Notifications toggle read state; Profile and Settings save local preferences.

Admin Overview shows six KPIs and five charts. Bookings supports detail and status management. Hall Management adds/edits records and enables/disables spaces; capacity, area, amenities and price are editable. Calendar navigates months, filters hall/capacity/event setup and lets the admin block/unblock demo dates or inspect a reservation. Packages, Catering and Decoration screens add/edit demo options and estimates. Client Management derives client summaries from booking records. Payments supports simulated installments and receipts. Messages shows read/unread enquiries and saves reply drafts without sending. Reports filters dates, summarizes hall/package utilization, redraws charts and exports CSV/print layouts. Notifications and Settings persist browser-local edits.

Chart values come from GV.state.bookings. Received revenue uses paid amounts on non-cancelled reservations and is grouped by event month. Monthly bookings and categories include the selected reservation records; status distribution explicitly includes cancellations. Payment totals exclude cancelled bookings. No random data or disconnected revenue series is used.

Calendars reserve full demo event dates, so a reservation blocks both displayed time slots. Selected event type describes the proposed setup; other event reservations still block that date. Dates in the past, blocked dates, deterministic reserved dates and disabled halls are unavailable. No availability is fetched from a real venue.
